我觉得可以把修改分成两条线：

# 第一部分：本周就能完成的重构（投入 1~2 天）

目标：

> 不增加任何新内容，仅重新组织已有内容。

这部分收益最高。

---

# 1. 首页结构重构

目前像：

```text
About
↓
课程
↓
项目
↓
技能
↓
博客
```

建议改成：

```text
About
↓
Research Interests
↓
Selected Projects
↓
Selected Notes
↓
Skills
↓
CV
```

因为老师一般只会看前两屏。

---

## About 改法

现在：

```text
兴趣方向包括：
计算数学
图形学
自动化
大数据
AI
深度学习
...
```

建议缩减为：

```text
Research Interests

• Scientific Computing
• Computer Graphics
• Geometry Processing
• Embodied Intelligence
• AI for Science
```

不要超过 5 个。

```text
Developed an integrated manipulation system
```

```text

LLM · Multi-Agent · Evaluation

Built a Judger–Reviewer–Writer framework
```

这样老师甚至不用点进去。

必须补。

## 1. 灵巧手项目

这是你目前最有辨识度的项目。

因为：

```text
数学本科
+
机器人
+
具身智能
```

这个组合很少。

---

建议单独做：

```text
projects/dexhand
```

结构：

```text
1 Motivation

2 System Architecture

3 Hardware

4 Software

5 Grasp Pipeline

6 Challenges

7 Results

8 Future Work
```

---

里面最好放：

* 系统框图
* 硬件照片
* 抓取视频

---

这是最值得投入的。

---

# 2. 长文本评测项目

这是第二优先级。

因为：

很多人会说：

```text
做过大模型
```

但老师不知道做了什么。

---

建议复盘：

```text
Problem

Framework

Judger
Reviewer
Writer

Prompt Design

Evaluation Metrics

Experiments

Lessons Learned
```

---

重点不要写：

```text
用了GPT
```

而写：

```text
为什么这样设计Agent
```

---

# 优先级 A

强烈推荐。

---

# 我认为最合理的最终结构

未来主页应该像：

```text
Home

About

Research Interests

Selected Projects
    DexHand
    LLM Evaluation
    MPM

Technical Notes
    PDE
    Wavelets
    Graphics

Reading Notes
    HOI
    World Models
    Geometry Processing

CV
```

其中真正需要你投入时间新写的，其实只有 4 篇：

1. DexHand Project Page
2. LLM Evaluation Project Page
3. MPM Project Page
4. PDE Project Page

如果这四篇写出来，我认为你的网站会从现在的“优秀学习博客”变成“具备科研作品集属性的学术主页”。

对于推免老师而言，这种变化比再多写十篇课程笔记更有价值。尤其是 **DexHand + MPM** 这两个项目，它们和你“应用数学背景转图形学/具身智能”的故事线是完全一致的。
