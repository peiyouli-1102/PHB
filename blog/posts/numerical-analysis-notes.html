常微分方程数值解

解的存在性和唯一性

常微分方程的一般形式为：\(x'(t) = f(t, x)\)，初始条件 \(x(t_0)=x_0\)。

第一存在性定理，初值问题：若\(f\)在中心为\((t_0,x_0)\)的矩形 $$R = {（t,x）:|t-t_0|\leq \alpha, |x-x_0|\leq \beta}$$ 内连续，则对于\(|t-t_0|\leq min(\alpha,\beta/M)\)初值问题有解\(x(t)\),其中M是\(|f(t,x)|\)在矩形R内的最大值.

唯一性定理，初值问题：若\(f\)和\(\partial f/\partial x\)在(2)式定义的矩形R内连续，则初值问题(1)在区间\(|t-t_0|< min(\alpha,\beta/M )\)内有唯一解.

存在性定理，初值问题：若\(f\)在带\(a\leq t\leq b, \quad -\infty < x < +\infty \)内连续并满足不等式 $$|f(t,x_1) - f(t,x_2)|\leq L|x_1 - x_2|$$则初值问题在区间\([a,b]\)上有唯一解.

欧拉法的递推公式为： $$ y_{n+1} = y_n + h \, f(t_n, y_n) $$ 其中 \(h\) 是步长。

泰勒级数方法

一大方法即通过列表（\(t_0,x_0）,(t_1,x_1)...\)递推计算 ，单步法，即只用前一步的信息

条件：\(f\)的各种偏导存在

泰勒级数方法：\(x =x + h(x' + \frac{h}{2}(x'' + \frac{h}{3}(x''' + \frac{h}{4}(x^{(4)})))) \)

好处：有任意高精度的潜力；坏处：要求很多导，复杂

舍入误差：计算机位数局限；舍入误差：算法误差

延迟微分方程法

龙格-库塔方法

推导： $$x(t+h) = x(t) + h x'(t) + \frac{h^2}{2!}x''(t) + \frac{h^3}{3!}x'''(t) + \cdots $$ 代入\(x' = f(t,x)\) $$x(t+h) = x + \frac{1}{2}hf + \frac{1}{2}h[f + hf_{t} + hff_{x}] + \mathcal{O}(h^3)$$ 代入\(f(t+h,x+hf) = f + hf_t +hff_x + \mathcal{O}(h^2)\) $$x(t+h) = x(t) + \frac{h}{2}f(t,x) + \frac{h}{2}f(t+h, x+f(t+x))$$

二阶龙格-库塔公式：\(x(t+h) = x + \omega_1 hf + \omega_2 hf(t+\alpha h, x+\beta hf)\); 条件\(\omega_1 + \omega_2 = 1; \omega_2\cdot\alpha = \omega_2\cdot\beta = \frac{1}{2}\)

四阶龙格‑库塔方法： $$x(t+h) = x(t) + \frac{1}{6}[F_1 + 2F_2 + 2F_3 + F_4]$$ $$F_1 = hf(t,x)$$ $$F_2 = hf(t+\frac{1}{2}h, x+\frac{1}{2}F_1)$$ $$F_3 = hf(t+\frac{1}{2}h, x+\frac{1}{2}F_2)$$ $$F_4 = hf(t+h, x+F_3)$$

四阶龙格‑库塔方法的局部截断误差为 \(\mathcal{O}(h^5)\)，整体误差为 \(\mathcal{O}(h^4)\)。

五个函数赋值地四阶方法 六个函数赋值地五阶方法 （龙格‑库塔-费尔贝格方法）

五阶公式记为\(x(t+h) = x(t) + \sum^{6}_{i = 1} a_i F_i\)

四阶公式记为\(\bar{x}(t+h) = x(t) + \sum^{6}_{i = 1} b_i F_i\)

\(F_i = hf(t+ c_i h , x + \sum^{i-1}_{j = 1} d_{ij} F_{j})\)
\(e = x(t+h) - \bar{x}(t+h)\)可以简略估计截断误差，因而可以控制步长，\(h = 0.9 h [\delta/|e|]^{1/(1+p)}\),p是阶数
