数值分析课程笔记整理

2026-05-06 · 数值分析 · 笔记

课程脉络（概要）

数值分析关心如何用离散、有限的计算近似连续数学问题，并在计算机浮点环境下理解误差来源（模型误差、截断误差、舍入误差）与稳定性。 主要分为三个章节：函数逼近/插值，数值微分/数值积分，常微分方程数值解，偏微分方程数值解

函数逼近

多项式插值

给定一组节点和函数值，构造次数不超过节点数减一的多项式使其精确经过所有数据点。拉格朗日形式和牛顿形式是两种常见表达，唯一性由代数基本定理保证。等距节点的高次插值容易出现龙格现象。

均差

均差（差商）是牛顿插值多项式系数的基础。\(k\) 阶均差 \(f[x_0,\dots,x_k]\) 可递归定义，与求导顺序无关，且在节点重合时退化为导数除以阶乘。均差表便于逐步增加节点。

埃米尔特插值

埃米尔特插值不仅匹配函数值，还匹配若干阶导数值。通常用广义牛顿均差或构造满足导数条件的多项式，其唯一性与误差公式可类比拉格朗日插值，但节点被视为有重数。

样条插值

样条插值在子区间上使用低次多项式，并在节点处保证函数值及若干阶导数的连续性，从而避免高次插值的振荡。最常用的是三次样条，需要附加自然、夹持或周期边界条件来确定唯一解。

B样条

B样条是样条空间的一组具有紧支撑的基底函数，通过节点序列的递推定义。它们具有局部控制、非负性和单位分割等优良性质，广泛应用于计算机辅助几何设计和数值逼近。

泰勒技术

将光滑函数在展开点邻域用泰勒多项式逼近，截断误差由拉格朗日余项或积分余项给出。随着展开阶数升高，逼近精度在收敛半径内提高，但需要函数足够光滑且高阶导数可计算。

最佳逼近：最小二乘理论

在离散数据或连续内积空间中，最小二乘逼近寻找使得残差的 \(L^2\) 范数最小的函数。通过法方程将问题转化为线性方程组求解，若基函数选取适当（如正交多项式），可避免病态并简化计算。

最佳逼近：切比雪夫理论

切比雪夫逼近在 \(L^\infty\) 范数（最大绝对偏差）意义下寻找最佳多项式。由切比雪夫交错定理刻画：最佳逼近多项式与目标函数的误差在至少 \(n+2\) 个点上交替达到最大绝对值。雷米兹算法是求解的经典方法。

高维插值（三角剖分）

对二维散乱数据，常将定义域划分为三角形网格（三角剖分），在每个三角形上构造分片线性或高阶多项式插值。需要处理网格生成和连续性条件，有限元方法中大量使用此类技术。

连分式

连分式是一种通过分式嵌套逼近函数的方式，如泰勒连分式或切比雪夫连分式。相比多项式逼近，连分式有时有更大收敛域和更好渐近性质，常用于特殊函数计算和有理逼近。

三角插值

对周期函数在等距节点上使用正弦、余弦的线性组合进行插值。三角插值是傅里叶分析在离散情形下的体现，当节点数等于谐波数时，插值是唯一的，并可通过快速傅里叶变换高效计算。

快速傅里叶变换（FTT）

快速傅里叶变换（FFT）是将离散傅里叶变换的计算复杂度从 \(\mathcal{O}(N^2)\) 降为 \(\mathcal{O}(N\log N)\) 的算法。利用单位根的对称性和周期性进行分治，是谱方法和信号处理的基石。

自适应逼近

自适应逼近根据函数的局部变化自动调整节点分布或多项式次数，以在满足精度要求的前提下最小化计算量。常见策略包括局部细分、hp-自适应等方法，在求解微分方程和稀疏网格逼近中广泛应用。

数值微分/数值积分

数值微分和理查森外推

数值微分通过差商近似导数，其误差可按步长展开为级数形式。理查森外推利用不同步长的计算结果组合消去低阶误差项，从而以较低代价显著提高近似精度。

基于插值的数值微分

先用插值多项式代替原函数，再对多项式求导作为数值微分。误差取决于插值余项的导数，对非光滑函数或噪声数据会放大高频扰动，需配合正则化或光滑化技术使用。

高斯求积

高斯求积通过选取最优节点和权重，使求积公式对最高次多项式精确成立。\(n\) 点高斯公式对不超过 \(2n-1\) 次多项式精确，节点为某正交多项式的根，权重可通过特征值问题或矩方程确定。

龙贝格积分

龙贝格积分在复合梯形公式的基础上反复应用理查森外推，逐步消去误差展开中的偶次幂项。其递推结构类似三角表，能自动生成高精度的积分近似，是实际中常用的自适应积分基础。

自适应求积

自适应求积根据函数在子区间上的误差估计自动决定是否细分，集中计算资源于变化剧烈的区域。通常使用两套不同阶数的求积公式（如辛普森与高斯）进行误差判断，直至满足全局容差。

逼近泛函的Sard定理

Sard定理在数值积分中给出了线性逼近泛函的误差界。它将误差表示为函数高阶导数与核函数（佩亚诺核）的积分，为比较不同求积公式的精度和构建最优公式提供了统一理论框架。

常微分方程数值解

解的存在性和唯一性

常微分方程的一般形式为：\(x'(t) = f(t, x)\)，初始条件 \(x(t_0)=x_0\)。

第一存在性定理，初值问题：若\(f\)在中心为\((t_0,x_0)\)的矩形 $$R = {（t,x）:|t-t_0|\leq \alpha, |x-x_0|\leq \beta}$$ 内连续，则对于\(|t-t_0|\leq min(\alpha,\beta/M)\)初值问题有解\(x(t)\),其中M是\(|f(t,x)|\)在矩形R内的最大值.

唯一性定理，初值问题：若\(f\)和\(\partial f/\partial x\)在(2)式定义的矩形R内连续，则初值问题(1)在区间\(|t-t_0|< min(\alpha,\beta/M )\)内有唯一解.

存在性定理，初值问题：若\(f\)在带\(a\leq t\leq b, \quad -\infty < x < +\infty \)内连续并满足不等式 $$|f(t,x_1) - f(t,x_2)|\leq L|x_1 - x_2|$$则初值问题在区间\([a,b]\)上有唯一解.

推导： $$x(t+h) = x(t) + h x'(t) + \frac{h^2}{2!}x''(t) + \frac{h^3}{3!}x'''(t) + \cdots $$ 代入\(x' = f(t,x)\) $$x(t+h) = x + \frac{1}{2}hf + \frac{1}{2}h[f + hf_{t} + hff_{x}] + \mathcal{O}(h^3)$$ 代入\(f(t+h,x+hf) = f + hf_t +hff_x + \mathcal{O}(h^2)\) $$x(t+h) = x(t) + \frac{h}{2}f(t,x) + \frac{h}{2}f(t+h, x+f(t+x))$$

二阶龙格-库塔公式：\(x(t+h) = x + \omega_1 hf + \omega_2 hf(t+\alpha h, x+\beta hf)\); 条件\(\omega_1 + \omega_2 = 1; \omega_2\cdot\alpha = \omega_2\cdot\beta = \frac{1}{2}\)

四阶龙格‑库塔方法： $$x(t+h) = x(t) + \frac{1}{6}[F_1 + 2F_2 + 2F_3 + F_4]$$ $$F_1 = hf(t,x)$$ $$F_2 = hf(t+\frac{1}{2}h, x+\frac{1}{2}F_1)$$ $$F_3 = hf(t+\frac{1}{2}h, x+\frac{1}{2}F_2)$$ $$F_4 = hf(t+h, x+F_3)$$

四阶龙格‑库塔方法的局部截断误差为 \(\mathcal{O}(h^5)\)，整体误差为 \(\mathcal{O}(h^4)\)。

方程组和高阶常微分方程

高阶常微分方程可引入新变量转化为一阶常微分方程组。数值方法可直接以向量形式应用，例如龙格‑库塔法对所有分量同步推进，误差分析同样适用于系统情形。

边值问题

边值问题在区间两端或内部给定约束条件，与初值问题不同，其解的存在性和唯一性更复杂。数值方法主要包括打靶法、有限差分法和配置法等，需要处理全局耦合而非递推求解。

边值问题：打靶法

打靶法将边值问题转化为初值问题，通过猜测缺失的初始条件进行迭代，调整初值使积分终点满足给定的边界条件。简单打靶法使用牛顿法修正初值，多重打靶法将区间分段以提高数值稳定性。

边值问题：有限差分法

有限差分法在网格上用差商代替导数，将微分方程离散为稀疏线性方程组。通过构造中心、向前或向后差分格式，并引入边界条件，最终求解代数方程组得到近似解，误差由网格尺寸和格式阶数决定。

边值问题：配置法

配置法假设解为若干基函数（如样条、多项式）的线性组合，然后在选定的配置点上强制满足微分方程和边界条件，形成关于待定系数的方程组。通过合理选择基函数和配置点，可达到高精度或谱精度。

线性微分方程

线性常微分方程的解具有叠加结构，齐次解空间维数等于方程阶数。数值方法通常将其离散为线性代数问题，可利用线性系统求解器高效处理，稳定性和收敛性理论也更加完善。

刚性方程

刚性方程的特征是其解分量呈现显著不同的时间尺度，显式方法受稳定性限制需极小步长。隐式方法（如向后微分公式、隐式龙格‑库塔）因具有更好的绝对稳定性而成为求解刚性问题的必要选择。
